JIRA TICKET TO MARKDOWN

Privacy policy

Effective August 23, 2026

Ticket processing stays in your browser. The extension has no analytics, advertising, accounts, or external servers.

Data handling

The extension processes the contents and URL of the Jira Cloud tab on which you explicitly activate it. This local processing creates an editable Markdown preview.

It does not transmit, sell, share, retain, or use Jira ticket content, URLs, selected text, or personal information outside your browser. Your character-limit preference is stored locally through Chrome extension storage.

Access and clipboard

The extension receives temporary access to the active tab only when you invoke it. It does not read other tabs or other Jira tickets. Copying Markdown places the reviewed text on your system clipboard at your request.

You are responsible for reviewing confidential information before pasting it into another service.

Contact and changes

Changes will be published here and with the extension listing. Questions can be submitted through the public support tracker.
