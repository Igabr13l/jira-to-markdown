# Product

## User and job

Developers and freelancers using Jira Cloud with coding tools need a clean issue brief without manually repairing copied text.

## Outcome

Open a Jira Cloud ticket, invoke the extension, review editable Markdown containing its key, title, description, acceptance criteria, URL, and selected text, then copy it.

## Main flow

1. The user opens one Jira Cloud ticket.
2. The popup reads only the active tab after the user invokes it.
3. The user edits the local preview and copies it.

## Success metric

Three users pay after the beta, and at least two repeat the flow during one week.

## Beta scope

- Jira Cloud on `*.atlassian.net`.
- Missing-field tolerance and a configurable 500-100,000 character limit.
- Local processing with no network calls or telemetry.

## Non-goals

Jira Server/Data Center, custom domains, other products, history, screenshots, automatic redaction, AI rewriting, accounts, or billing.
